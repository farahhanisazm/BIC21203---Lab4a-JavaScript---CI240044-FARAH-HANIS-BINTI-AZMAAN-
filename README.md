## Introduction

This laboratory activity focuses on client-side scripting
using HTML, CSS and JavaScript. Three interactive webpages
were developed to demonstrate JavaScript functions,
event handling, input validation, loops and DOM manipulation.

## Question 1 - Interactive Text Changer

This webpage allows users to change the original message
from "Welcome to my website!" to "Hello there!" by clicking
the Change Message button.

## Question 2 - Smart Number Validator

This webpage validates user input and determines whether
the entered number is lower than, higher than or equal
to 10. Invalid and empty inputs display an error message.

## Question 3 - Dynamic Number Generator

This webpage generates an ordered list of numbers from
1 to 5 using a JavaScript for loop. Existing list items
are cleared before generating new items to prevent
duplicate results
